# Projects

Kleine Spiele zum Zeitvertreib. GitHub Pages liefert alles von `main` aus, jedes
Spiel hat seine eigene Adresse, die Startseite verlinkt beide:

| | Ordner | Adresse |
|---|---|---|
| Startseite | `index.html` | https://babypython67.github.io/Projects/ |
| Johannisnacht, Glühwürmchen-Spiel | [johannisnacht/](johannisnacht/) | https://babypython67.github.io/Projects/johannisnacht/ |
| Deichgraf, Sturmflut-Spiel (Handy und Terminal) | [spiel/](spiel/) | https://babypython67.github.io/Projects/spiel/ |

`london-sporttag/` enthält nur noch eine Weiterleitung zur Johannisnacht, damit alte Links und
zwischengespeicherte Startseiten nicht ins Leere laufen.

`.nojekyll` sorgt dafür, dass Pages die Dateien unverändert ausliefert, statt sie durch Jekyll
zu schicken (ohne die Datei zeigt Pages für Ordner ohne `index.html` deren README an).
